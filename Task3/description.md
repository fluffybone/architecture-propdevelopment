**Требования к безопасности**

1. Все данные, передаваемые между внешней платформой (партнёра) и системой PropDevelopment, должны передаваться по защищённому каналу TLS.
2. Передача биометрических данных (изображения лица) и номеров автомобилей должна быть зашифрована на уровне приложения (использовать шифрование PostgreSQL)
3. Доступ к API внешних сервисов должен быть ограничен по IP-адресам (whitelist) серверов PropDevelopment.
4. Cистема должна соответствовать требованиям ФЗ-152 «О персональных данных», особенно при обработке биометрических данных.
5. Партнёр обязан предоставить документы о безопасности

**Протоколы аутентификации и авторизации**

1. Доступ к функциям «Умный дом» в мобильном приложении должен быть авторизован через существующую систему авторизации PropDevelopment.
2. Используется OAuth 2.0 или JWT с подписью для аутентификации сервер-серверного взаимодействия.
3. Каждая сторона обменивается публичными ключами для проверки подписей.
4. При запросе к внешнему сервису (например, открытие двери) PropDevelopment выступает как доверенный прокси, передавая пользовательский токен, который содержит информацию о пользователе и действие. Внешняя платформа проверяет подпись токена и разрешает действие, если права есть.
5. Приложение использует обновляемые токены (refresh tokens).
6. Повторная аутентификация нужна после неактивности втечении 30мин.

**Архитектура интеграции**

 Пользователь открывает Витрину сервисов для собственников -> может перейти в приложение управлением "Умный дом". В котором у него есть доступ к управлению Домофоном и шлагбаумом, функции умного дома реализованы на стороне партнера, со стороны PropDevelopment -> должна осуществляться авторизация, аунтификация.
 В БД Умного дома будет хранится состояние устройств дома, подключенные услуги которыми можно управлять, и логи неудачных попыток управлением устройства

 Хранение данных собственников на стороне PropDevelopment, у партнера только обезличенный id или token 

 При передачи видео с домофона, запись сохраняется в бд PropDevelopment Умный дом, в момент самого звонка запись шифруется при взаимодействии с сервисом партнера, и после окончании звонка не хранится на сервисе партнера.

 PropDevelopment выступает как единая точка входа для пользователей через мобильное приложение.
 Взаимодействие с внешними сервисами происходит через RESTful API
 
 PropDevelopment периодически синхронизирует:
 * Список пользователей с правами доступа.
 * Разрешённые номера автомобилей
